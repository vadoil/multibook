# Multibook — правила для Codex и других агентов

Интернет-магазин модульных блокнотов на дисках (multi-book.ru). Next.js 16 (App Router, Turbopack), React 19, TypeScript 5, Tailwind CSS v4, SQLite + Drizzle ORM.
Тексты сайта — на русском. Подробный план и решения — `docs/PLAN.md`, заметки для Claude — `CLAUDE.md`.

## Кто что делает
- **Codex — визуальный дизайн**: вёрстка, типографика, цвет, сетки, анимации, мобильная версия, состояния (hover/focus/пусто/загрузка).
- **Claude — логика**: данные, оплата, доставка, вход, админ-действия. Codex эти части не меняет.

## Можно менять
- `src/app/globals.css` — дизайн-токены (`@theme`: цвета, радиусы, шрифты). Палитру меняйте здесь, а не цветами в компонентах.
- Разметку и классы в `src/app/**/page.tsx`, `src/app/layout.tsx`, `src/components/**`.
- Шрифты в `src/app/layout.tsx` (сейчас Manrope + Unbounded, обязательно с кириллицей).
- Новые чисто визуальные компоненты в `src/components/`.

## Нельзя менять (или только по согласованию в PR)
- `src/lib/auth.ts`, `orders.ts`, `payments.ts`, `delivery.ts`, `cart.ts`, `import-tilda.ts`, `normalize.ts`, `src/db/**`.
- Любые `actions.ts` (server actions) и `src/app/api/**`.
- Пропсы и данные, которые страницы получают с сервера: если нужно другое поле — опишите в PR, Claude добавит.
- Имена полей форм (`name="phone"` и т.п.) и `action={…}` у форм — на них завязан сервер.

## Правила дизайна
- **Фото товаров — только настоящие** из каталога (`product.images`, домены tildacdn). Не генерировать и не рисовать товары. Рисованные блокнот и диски допустимы только в конструкторе (`NotebookPreview`, `Swatches`).
- Мобильная версия обязательна: на ширине 375 px без горизонтальной прокрутки; кнопки не меньше 44 px.
- Доступность: видимый фокус, `alt`, подписи у полей, контраст текста ≥ 4.5:1, `prefers-reduced-motion` отключает анимации.
- Без тяжёлых UI-библиотек и без смены Tailwind. Анимации — CSS; если нужна библиотека, обоснуйте в PR.
- Тон текстов — живой и простой, без канцелярита и маркетплейсных штампов.

## Запуск
```bash
npm ci
npx drizzle-kit push --force   # создать базу data/multibook.db по схеме
npm run import:tilda           # загрузить каталог из публичного API Tilda (нужен интернет)
npm run dev:admin              # локальный админ, пароль — в .env.local
npm run dev                    # http://127.0.0.1:3000
```
Без ключей оплата и доставка работают в демо-режиме: это нормально.

## Перед PR
- `npx tsc --noEmit` и `npm run build` без ошибок.
- Скриншоты изменённых страниц: десктоп 1366 px и телефон 375 px.
- Одна тема — одна ветка `design/<тема>` и один PR. Не трогайте файлы, не относящиеся к теме.

# Как обновить сайт на сервере (sport-brend.ru)

На 24.11.2026 на sport-brend.ru стоит старая сборка: там нет контент-завода, страницы маркетплейсов, хлебных крошек и правок по 152-ФЗ. Всё это есть в ветке `main` на GitHub.

На сервере, в папке проекта:

1. Сделать копию базы: скопировать `data/multibook.db` вместе с файлами `-wal` и `-shm`.
2. `git pull origin main`
3. `npm ci`
4. `npm run db:upgrade` — добавит новые колонки и таблицы, существующие данные не трогает.
5. В `.env` на сервере добавить (образец — `.env.example`):
   - `SITE_URL=https://sport-brend.ru` — от него строятся ссылки в постах, карта сайта и адрес в политике;
   - `NORDROUTER_API_KEY=…` — без него контент-завод пишет тексты по шаблону, без ИИ;
   - по желанию: `TELEGRAM_CHANNEL_ID`, `VK_ACCESS_TOKEN`, `VK_GROUP_ID`, `OZON_CLIENT_ID`, `OZON_API_KEY`, `WB_API_TOKEN`.
6. `npm run build` и перезапустить приложение.
7. Войти под админом: `https://sport-brend.ru/admin/content` и `https://sport-brend.ru/admin/marketplaces`.

Если админа на сервере ещё нет: зарегистрироваться на сайте, затем `npm run admin:grant -- почта`.

До запуска для покупателей: убедиться, что сервер находится в России (152-ФЗ, локализация данных).

# Задание для Codex: дизайн Multibook

Вставьте текст ниже в Codex (облачный, подключённый к репозиторию на GitHub). Правила работы он прочитает сам из `AGENTS.md`.

---

Сделай визуальный дизайн сайта Multibook — магазина модульных блокнотов на дисках. Логика уже работает; твоя задача — чтобы сайт выглядел «вау» и продавал. Соблюдай `AGENTS.md`: не меняй server actions, `src/lib/*` и данные; фото товаров — только настоящие.

Характер бренда: тёплая бумага, ремесло, порядок в голове. Главная фишка продукта — листы снимаются и переставляются, блокнот собирается как конструктор. Сейчас токены в `src/app/globals.css`: бумажный фон #f5f1ea, чернила #1d1c1a, акцент красный #c8302a. Можно развить палитру, но сохранить тепло и бумагу.

Делай по одной теме на ветку и PR, в таком порядке:

1. `design/system` — токены (цвет, типографика, радиусы, тени), шапка и подвал, кнопки, поля, бейджи. Мобильное меню в шапке (сейчас на телефоне видны только «Каталог», кабинет и корзина).
2. `design/home` — главная `src/app/page.tsx`: первый экран с каруселью фото (`HeroGallery`), блок «как работает дисковый переплёт» (сейчас три карточки — сделай наглядно: анимация снятия и перестановки листа на CSS), категории, хиты, призыв в конструктор.
3. `design/catalog` — каталог, карточка товара `ProductCard`, страница товара `src/app/product/[slug]`, витрина дисков `DiscCatalog`.
4. `design/constructor` — конструктор `src/components/Constructor.tsx` + `NotebookPreview` + `Swatches`: полировка, анимации выбора, мобильная версия. Логику выбора и расчёта не меняй.
5. `design/checkout` — корзина `CartView`, страница заказа `src/app/order/[token]`, демо-оплата `src/app/pay/demo`.
6. `design/account` — кабинет `src/app/account` и формы `AccountForms`. Админку (`src/app/admin`) — только аккуратно и единообразно, без украшательств.

К каждому PR — скриншоты десктопа (1366 px) и телефона (375 px), проверка `npx tsc --noEmit` и `npm run build`.

# Видимый переход между вариантами 1–2–3

На главной тестового магазина под шапкой появилась панель из одобренных контурных табов: 1 — «Бумажная мастерская», 2 — «Предметный журнал», 3 — «Конструктор идей». Кнопка «Магазин» возвращает к текущей главной. Ссылка «Варианты дизайна» / «Дизайн» открывает общее сравнение.

Та же панель расположена над каждой концепцией; текущая страница отмечена акцентным контуром и `aria-current`. На телефоне названия сокращены до цифр, полные названия остаются в доступных подписях. Все ссылки имеют область нажатия от 44 px; на 320 px панель помещается без горизонтальной прокрутки. Переключение идёт по обычным адресам. Предзагрузка концепций отключена, чтобы они не расходовали память сервера до перехода.

Панель и концепции доступны при `DESIGN_PREVIEW=1`, включённом только в окружении тестового sport-brend.ru. Без флага главная работает как раньше, все четыре адреса предпросмотра возвращают 404. Layout концепций сделан динамическим, чтобы флаг читался при запросе и 404 не фиксировался во время сборки.

На остальных страницах магазина панель не занимает место: каталог, конструктор и оформление сохраняют высоту шапки. На главной высота hero учитывает дополнительный ряд, элементы управления остаются в первом экране.

Типографика, содержимое концепций, данные, `src/lib`, `src/db`, API, server actions и расчёты не менялись. Исправление памяти из предыдущего PR сохранено.

Проверено: `npx tsc --noEmit`, production build; 21 проверка переходов и компоновки на 1366/375/320/768 px, возврат в магазин, общий обзор и мобильное меню. Отдельно проверены главная и четыре закрытых адреса без флага. JSON и скриншоты 1366/375 px находятся рядом.

# Одна страница в превью конструктора

Вместо двух узких страниц режим «Страница» показывает один лист в пропорциях выбранного формата. Переключатель подписан «Обложка / Страница», его кнопки имеют высоту не менее 44 px. На телефоне превью увеличено. Страница не покачивается автоматически; наклон мышью отключён при reduced motion и для касаний.

Выбор деталей, кодирование сборки в URL, совместимость, количество листов, цена и добавление в корзину не изменены.

Проверено:

- `npx tsc --noEmit` и `npm run build` проходят.
- На 1366 и 375 px горизонтальная прокрутка отсутствует; после переключения сборка в URL и сумма 1 767 ₽ сохраняются.
- Режим обложки восстанавливается; показ страницы работает для А5, мини евро и мини куба.
- В режиме страницы отображается один слой разметки; пропорции листа А5 сохранены.

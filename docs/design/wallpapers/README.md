# Обои Multibook

Семь фотокомпозиций, пять настоящих блокнотов и шесть окружений: утренний дуб, лён, ореховый стол, гербарий, мастерская, зимний подоконник. Для телефона композиции собраны отдельно: товар находится ниже кнопок, целиком в кадре.

Окружения созданы встроенным `image_gen`; набор промптов — `prompts.json`, сохранённые окружения — `environments/`. Товары не подавались в генератор. Их RGB взят из оригинальных фотографий Tilda, фон удалён масками из `masks/`; тени получены из силуэтов. `sources.json` хранит URL, UID и SHA-256 каждого оригинала. Надписи, являющиеся частью настоящего тиснения на товаре, сохранены.

Воспроизводимая сборка: `node scripts/make-editorial-wallpapers.mjs`. Скрипт проверяет SHA-256, накладывает маски и собирает WebP четырёх размеров. Оригинальный `make-wallpapers.mjs` оставлен как независимый способ пересобрать прежние студийные обои.

- `asset-check.json`: фактические размеры, вес и качество каждого файла; первый кадр ≤200 000 байт, остальные ≤350 000.
- `layout-check.json`: 1366×768, 1920×1080 и 375×812; все семь кадров, ссылки на настоящие товары, отсутствие горизонтального переполнения, интерактивные цели ≥44 px.
- `contrast-check.json`: минимальный контраст под всей площадью заголовка и описания на каждом широком кадре. Проверка по скриншотам с временно скрытым текстом, с учётом вуали.
- `desktop-1366.png`, `mobile-375.png`, `evening-1366.png`: проверенные скриншоты.

Проверки: `npx tsc --noEmit`, `npm run build`. Для локальной проверки использована отдельная копия каталога с уже добавленным Claude полем `featured`; исходная база не изменена. Серверные действия, расчёты, `src/lib/*`, `src/db/**` и API не менялись.

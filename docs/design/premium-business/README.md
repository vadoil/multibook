# Премиальные ежедневники: деловая среда

Первый экран собран вокруг настоящих ежедневников и шести деловых сцен: Москва-Сити утром и вечером, переговоры, кабинет для коучинга, корпоративная академия, кабинет руководителя. Каждый интерьер создан отдельно в 16:9 и 9:16; вертикальная версия сохраняет город или интерьер рядом с товаром. Первым показывается чёрный «Важная птица» с золотым тиснением и актуальной ценой из каталога.

Только окружения созданы встроенным `image_gen`. Файлы сохранены в `environments/`, точные промпты — `prompts.json`. Товары взяты с исходных фотографий Tilda из `../wallpapers/sources.json`, проверены по SHA-256 и вырезаны теми же масками. Их обложки, рисунки, надписи и диски не генерировались и не перерисовывались. Тень на столе строится из силуэта фотографии.

Сборка: `node scripts/make-premium-wallpapers.mjs`. Готовые WebP и прежний формат манифеста — `public/hero/`. Список сцен — `scenes.json`, размеры и вес — `asset-check.json`. Первый кадр 167 870 байт на 2560×1440, 80 604 на 1600×900 и 98 818 на телефоне 1080×1920; качество 82. Остальные кадры не превышают 350 КБ.

В hero прямо показаны два пути: готовые ежедневники и конструктор. На телефоне заголовок компактнее, название и цена объединены в широкую удобную ссылку. Подсказки миниатюр называют деловую сцену. Карусель сохраняет таймер, паузу, свайп, управление клавиатурой и уменьшение движения. На 404 также используется новая фотография с Москва-Сити.

Проверки: `npx tsc --noEmit`, `npm run build`, шесть сцен на 1366×768, 1920×1080, 375×812. Минимальный измеренный контраст под всей площадью заголовка и описания — 7,83:1. Все ссылки ведут на настоящие товары; цели от 44 px; горизонтального переполнения нет. Отчёты — `layout-check.json`, `contrast-check.json`; скриншоты — `slide-*.webp`.

Ветка основана на `design/audit-fixes`. Поля серверных данных, расчёты, действия, API и каталог не менялись.

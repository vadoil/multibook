# Multibook: деловая коллекция

Премиальные ежедневники для переговоров, работы с коучем и корпоративного обучения. Шесть сцен: утренний и вечерний Москва-Сити, переговорная, кабинет для коучинга, корпоративная академия, кабинет руководителя. Первым показывается настоящий чёрный ежедневник «Важная птица» с золотым тиснением.

Сохраняются брендовые бумага `#eee7db`, карточка `#faf5ec`, чернила `#462c2b`, акцент `#823a31`, приглушённый `#6f5b53`. В фотографии добавляются шампань, орех, коньячная кожа и латунь. Шрифты — кириллические Cormorant Garamond для заголовков и Golos Text для интерфейса.

Десктоп: спокойная колонка слева, архитектурная фотография справа, настоящий ежедневник на переднем плане и док выбора сцен. Телефон: компактный заголовок → два прямых пути покупки → вертикальная фотография с видимым интерьером → название, цена и выбор сцены. Никаких вымышленных клиентов, логотипов компаний, рейтингов или ссылок на магазины приложений.

Рекомендации ui-ux-pro-max использованы для размеров касаний, безопасных отступов и навигации. Визуальная система сохраняет Multibook; стек — существующий Next.js. Окружения созданы встроенным image_gen в двух отдельных композициях для каждой сцены. Реальные товары вставляются масками с сохранением исходных пикселей и проверкой SHA-256.

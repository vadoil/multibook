# Как устроен блокнот — исходные материалы Multibook

Пункт «Как устроен блокнот» в шапке и подвале ведёт на `/video`. На странице собраны оригинальные материалы с https://multi-book.ru/video: демонстрационный ролик, инструкция снятия и установки листа, пять схем (блоки, обложки/вкладки, перфорация, сочетание размеров, диски), требования к макетам и обращению с бумагой. Есть переходы в магазин, конструктор и к блокнотам на заказ. На главной в блоке механики — то же исходное видео и ссылка на инструкцию; на телефоне ролик показан перед текстом.

Видео «Мультибук — как использовать дисковый переплет» издателя «Артворк#381» сохранено без изменения кадров и звука в исходном MP4 720p (42,54 с, 7,45 МиБ). Встроенный плеер VK возвращал ошибку, хотя ролик воспроизводился отдельно. Локальная копия запускается нативным плеером с одного нажатия, работает inline на телефоне. До нажатия видео не загружается. Закрытие останавливает его и возвращает фокус на кнопку. Ссылка на оригинальную публикацию сохранена. Источник и SHA-256 — `video-source.json`.

Фотографии и схемы не перерисованы: WebP получены из оригиналов Tilda, всего 366 КБ. URL и SHA-256 оригиналов — `sources.json`; подготовка — `scripts/prepare-binding-guide.py`. У схем есть открытие в полном размере, а размеры блоков дополнительно выведены читаемым HTML. Исходная схема вместимости дисков подписана как расчёт для бумаги 100 г/м²; расчёт конструктора не менялся. Страница добавлена в sitemap.

`src/lib`, `src/db`, API, server actions, поля форм, цены и серверные пропсы не менялись. Зависимостей сайта не добавлено. Для повторного получения исходного ролика можно использовать `yt-dlp --no-playlist -f url720 -o public/media/disc-binding-original.mp4 https://vk.com/video-219099749_456239045`; версия источника проверяется по SHA-256.

Проверки:

- `npx tsc --noEmit`, `npm run build` — успешно.
- На 1366/375/320/768 px: переходы из меню, пять схем, клавиатура, открытие крупно, аккордеоны макетов, отсутствие ранней загрузки видео, остановка и возврат фокуса, контролы от 44 px, отсутствие горизонтального переполнения и ошибок JavaScript.
- На 1366/375 px отдельно подтверждено настоящее воспроизведение видео с одного нажатия: `paused=false`, время продвигается, длительность 42,54 с, изображение 1280×720.
- HTTP Range к видео возвращает 206 Partial Content (`bytes 0-31/7807278`).

Отчёты — `check.json`, `video-check.json`. Скриншоты 1366/375 px: страница, схемы, видео в работе и обновлённый блок главной.

# Внедрение дизайна в магазин

Журнальная концепция становится основной главной по адресу `/`. Переключатель концепций остаётся только в `/design-preview`. Главная показывает готовые блокноты с настоящими фотографиями и ценами, видео сборки, конструктор, механику переплёта и категории с пиктограммами.

Общая шапка, подвал и favicon используют фирменный знак с мотивом дисков. Название перехода в навигации и hero — «Конструктор». Счётчик корзины работает через существующий `CartLink` и `useCart`. Мобильное меню закрывается по Escape и после выбора ссылки.

Токены перенесены в `src/app/globals.css`: бумага `#eee7db`, чернила `#462c2b`, акцент `#823a31`, приглушённый текст `#6f5b53`, карточка `#faf5ec`, линия `#d0c3b5`. Шрифты с кириллицей — Golos Text и Cormorant Garamond, рукописная деталь — Caveat. Общие поля и кнопки получают доступный фокус и размеры для касания. Контраст статусов усилен: предупреждение `#93411e`, успех `#2b633f`; на полупрозрачных фоновых бейджах контраст не ниже 4,5:1.

На телефоне изображение располагается сразу под заголовком. Hero-заголовки уменьшены до 39–40 px. На ширине 375 px оба действия основной главной заканчиваются на 663 px: они доступны даже при высоте окна 667 px. Все три варианта получили компактные мобильные композиции. На обычных страницах магазина используются общие цвета, шрифты, поля и кнопки.

Админка сохраняет обычную гарнитуру Golos Text и обходится без декоративного подвала. Её проверка доступа не изменена.

Неработающие ссылки из прежней шапки заменены действующими маршрутами и якорями. Ссылки на политику, контакты, условия оплаты и корпоративную продукцию ведут на уже опубликованные страницы бренда:

- https://multi-book.ru/privacy
- https://multi-book.ru/contacts
- https://multi-book.ru/oplata
- https://multi-book.ru/corporatives

Тексты документов не переписывались. Фотографии и данные товаров не менялись. Server actions, API, `src/lib` и `src/db` не изменялись; имена полей и обработчики форм совпадают с предыдущей версией.

## Проверки

- `npx tsc --noEmit` и `npm run build` — успешно.
- `npx tsx --test docs/design/catalog/complements.test.ts` — 3 теста успешно.
- Главная, три варианта, каталог, диски, товар, конструктор и кабинет проверены на 1366 и 375 px: одна видимая шапка, изображения загружаются, горизонтальной прокрутки нет.
- Проверены мобильное меню, Escape, подпись «Конструктор», видео и сокращение движения.
- Сборка `/constructor?f=a5&c=20&b=96&d=203` сохраняет цену 1 767 ₽ при переключении «Обложка / Страница».
- На отдельной локальной QA-базе пройден путь: товар → корзина → оформление → заказ → демо-оплата → оплаченный заказ. Затем регистрация, вход и проверка защищённого доступа в админку.
- Тестовые покупатель, заказ и платёж существуют только в игнорируемой локальной QA-базе. Они не копируются на сервер и не входят в репозиторий.

Скриншоты `*-1366.png`, `*-375.png`, `home-375x667.png` и результаты проверок находятся рядом. Скриншоты статусов сняты в ходе функциональных проверок; семантические цвета дополнительно затемнены после измерения контраста.

## Развёртывание

После сборки используются standalone-выход Next.js, `.next/static` и `public`. Настоящая база и Linux-зависимости остаются в `/srv/multibook-preview/shared`. Релиз проверяется на временном порту 4318, затем атомарно меняется ссылка `current` и перезапускается только `multibook-preview.service`.

В конфигурации Nginx для sport-brend.ru необходимо удалить прежнее правило `location = / { return 302 /design-preview; }`, чтобы корень открывал основную главную. Остальные правила домена, HTTPS и настройки соседних сайтов сохраняются. База, переменные окружения, native-зависимости macOS и локальная QA-база не включаются в архив релиза. Предыдущий релиз и конфигурация сохраняются для отката.

# Продолжение видео с фокусом на кнопке

Раньше после нажатия «Продолжить» видео оставалось на паузе, пока курсор или фокус находился внутри блока. Явная команда запуска теперь имеет приоритет над автоматической паузой при наведении и фокусе. Вызов `play()` выполняется непосредственно при нажатии — в том числе при касании на телефоне.

Пауза по кнопке, остановка вне экрана и сокращение движения сохраняются. Видеофайл и сама анимация не менялись.

Проверено на 1366 и 375 px: мышь, Space с оставшимся фокусом на кнопке, отдельный браузерный контекст с сенсорным вводом, остановка вне экрана и статичный режим. `npx tsc --noEmit` и `npm run build` прошли. Скриншоты показывают запущенное видео при фокусе на кнопке.

# Количество аксессуаров в конструкторе

В карусели «Что ещё добавить?» у каждого из 24 аксессуаров есть «−», количество и «+». Счётчик подписан «В корзине»: нажатие сразу добавляет или убирает одну штуку через существующие `cart.add` и `cart.setQty`. Ноль означает, что товар не выбран; нижняя граница — 0, верхняя — существующий `MAX_QTY` (99). У недоступного товара добавление выключено, но уже выбранные штуки можно убрать.

Количество берётся из существующего `useCart`, поэтому сохраняется после перезагрузки и возврата из карточки товара. Аксессуары остаются отдельными позициями корзины. Кнопки не вложены в ссылку на товар. Общий визуальный счётчик вынесен из `Constructor` в `QuantityControl`; выбор и расчёт блоков не изменены.

`src/lib`, база, API, server actions, поля форм и серверные пропсы не менялись. Корзина и серверные цены используются через существующие интерфейсы.

Проверено на 1366/375 px: шаг 1, границы 0/99, независимые количества, сохранение при перезагрузке и возврате, итог корзины по серверным ценам, сохранение сборки при удалении аксессуара, прежний счётчик блоков, клавиатура, размеры кнопок ≥44 px, отсутствие вложенных кнопок и горизонтального переполнения. Ошибок JavaScript нет. `npx tsc --noEmit` и `npm run build` прошли.

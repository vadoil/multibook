# Ясная ссылка на версию с фонами

Кнопка «Магазин» в панели концепций переименована в «С фонами»: она открывает актуальную главную с интерьерными фотографиями. Цифры 1–2–3 по-прежнему ведут к ранним эскизам. На узких телефонах скрывается иконка, а текст кнопки остаётся видимым.

Проверены переход из журнального эскиза на главную, наличие фоновых слайдов, активная ссылка и отсутствие переполнения на 1366, 375 и 320 px. TypeScript и production build проходят. Данные и бизнес-логика не изменены.

# Обложка на первом фото

Карточка в каталоге и галерея товара используют один порядок фотографий. У тетрадей первым снова показывается закрытая обложка: прежний общий выбор `images[1]` выводил линовку или страницы планера. Для ежедневников и мини-блокнотов выбраны проверенные фотографии закрытых обложек из их существующих галерей. Точные источники и исходные позиции всех 74 тетрадей/блокнотов записаны в `sources.json`; подборка — `covers-contact.jpg`.

Предпочтительный снимок привязан к точному URL и UID товара. Если после импорта этого снимка больше нет, используется первый доступный снимок каталога. Остальные фото сохраняются в прежнем относительном порядке, без удаления и без изменения исходного массива. Первый миниатюрный снимок и счётчик соответствуют большому фото. Для товаров с обложкой используется `object-contain`, чтобы обложка помещалась целиком.

Для аксессуаров, блоков и дисков прежний выбор превью сохранён. Состав премиальной подборки на главной тоже сохранён. Новых зависимостей и изображений товаров нет: используются только оригинальные URL каталога. База, `src/lib`, server actions, API, серверные пропсы и расчёты не менялись.

Проверки:

- `npx tsc --noEmit` и `npm run build` — успешно.
- На 1366 и 375 px проверена 101 карточка: 57 тетрадей (обе страницы), 17 блокнотов и 27 обложек.
- На трёх разных товарах проверены первое фото, сохранение всех исходных снимков, выбор миниатюр, возврат на обложку с клавиатуры, отсутствие обрезки и горизонтального переполнения. Ошибок JavaScript нет.

Сводка — `check.json`. Скриншоты каталога и карточки товара: `catalog-1366.webp`, `catalog-375.webp`, `product-1366.webp`, `product-375.webp`.

# Живые сцены и навигация

Плашки заменяют сплошную вуаль над фотографией. Интерьер виден по всей площади первого экрана. Добавлены настоящий ракурс лежащего ежедневника с ручкой, раскрытый ежедневник и ежедневник на мраморной подставке. Все три положения показывают реальные фотографии товара; генератор не получал и не перерисовывал товар.

Окружения и отдельная рука с ручкой созданы встроенным `image_gen`. Точные промпты: [prompts.json](prompts.json); материалы сохранены в `environments/`. Фотографии каталога, URL и SHA-256: [sources.json](sources.json). Маски: `masks/`. Генерация трёх композиций: `python3 scripts/make-lifestyle-wallpapers.py` (Pillow, numpy, OpenCV; только инструменты подготовки материалов). Производственные изображения: `public/hero/lifestyle-*.webp`.

Для телефона предусмотрена отдельная вертикальная композиция. Первый кадр телефона — 192 КБ, на экране 1366 px — 181 КБ. Широкий вариант 2048 px сохраняет детали интерьера. Текст на сплошных бумажных плашках; контраст не зависит от кадра. Управление каруселью, свайп, пауза и режим уменьшенного движения сохранены.

Меню получило единые иконки с мотивом переплёта, акцентный конструктор, контурные кнопки кабинета и корзины, подписанную кнопку открытия меню. В телефоне активная вкладка выделяется чернилами. Размеры и расположение нижней панели и панели покупки сохранены.

Проверено: `npx tsc --noEmit`, `npm run build`, все шесть кадров на 1366 и 375 px, дополнительные 320, 430 и 768 px, работа меню и Escape. Цели от 44 px, горизонтального переполнения и ошибок JavaScript нет. Скриншоты и `layout-check.json` рядом. Оплата, заказы, вход, действия и данные не менялись.

# Три визуальных направления Multibook

Это отдельные страницы для выбора дизайна перед работой над `design/system`. Основная витрина и рабочие процессы магазина пока используют текущий дизайн.

| Направление | Страница | Характер |
| --- | --- | --- |
| 01. Бумажная мастерская | `/design-preview/paper` | Своя типография, бумага, фотографическая сборка блокнота при прокрутке |
| 02. Предметный журнал | `/design-preview/journal` | Крупная кириллическая антиква, асимметрия, предметная фотография |
| 03. Конструктор идей | `/design-preview/play` | Цветные модули, крупный гротеск, акцент на перестановке деталей |

Обзор направлений: [sport-brend.ru/design-preview](https://sport-brend.ru/design-preview). Тестовый домен открывает выбор концепций вместо исходной главной.

## Просмотр локально

```sh
npm ci
mkdir -p data
npx drizzle-kit push --force
npm run import:tilda
npm run dev
```

Каталог загружается из публичного API Tilda. Все фотографии, цены и ссылки на товары берутся из существующего каталога. Формулировка о своей типографии добавлена по указанию владельца.

## Айдентика и категории

Знак M построен на мотиве прорезей переплёта. Он используется в шапке, подвале и favicon. Для семи категорий добавлены навигационные SVG-пиктограммы с одинаковой толщиной линий и красными деталями. При наведении и фокусе слои иконок раздвигаются; reduced motion отключает переходы. Пиктограммы добавлены по прямому запросу владельца; фотографии товаров остаются настоящими.

[Категории, 1366 px](categories-desktop-1366.png) · [Категории, 375 px](categories-mobile-375.png)

## Первый экран мастерской

На компьютере прокрутка удерживает первый экран и управляет четырьмя этапами: печатные листы, установка дисков, обложка, раскрытие и перелистывание. Обложка и диски — CSS-вырезки из настоящей фотографии «Красных коней»; страницы используют фотографию бумажного блока. В финале появляется исходная фотография разворота. Движение обратимо при прокрутке вверх.

Анимация использует CSS view timeline, без перехвата колеса прокрутки, библиотек анимации и WebGL. На телефоне, в браузерах без поддержки timeline и при `prefers-reduced-motion: reduce` показывается собранный блокнот без длинного закреплённого экрана.

## Проверки

- `npx tsc --noEmit` — успешно.
- `npm run build` — успешно.
- Все три направления проверены на production-сборке при ширине 1366 и 375 px.
- Проверены фотографии, отсутствие горизонтальной прокрутки, мобильное меню, Escape с возвратом фокуса, размеры кнопок и переключение карусели.
- Проверены этапы scroll-анимации, обратная прокрутка и reduced motion.
- Основные пары цветов для текста: контраст от 4.52:1; вспомогательный текст журнального варианта на подложке — 4.72:1.

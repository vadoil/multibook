# Один лист и крупный ежедневник

Заголовок, описание и кнопки находятся на одном фирменном листе с сеткой и открытой перфорацией. Вместо увеличения всего фонового кадра выделен отдельный слой настоящего товара: он целиком вписывается в правую часть через `object-fit: contain`. На телефоне лист компактный, товар размещён под ним, над ценой и управлением кадрами. Кадр с рукой полностью исключён из активной карусели — осталось пять разных ежедневников.

Перфорация вырезана из подложки SVG-маской; фотография видна через отверстия. Фокус кнопок не обрезается маской. Новых шрифтов, UI-библиотек, анимаций или генерации товаров нет. Пауза, свайп, управление с клавиатуры и `prefers-reduced-motion` сохранены.

Фотографии взяты из каталога. URL и SHA-256 в [sources.json](sources.json). Для чёрного ежедневника на подставке выбран подлинный фронтальный ракурс из его галереи; источник и маска в [product-overrides.json](product-overrides.json) и `masks/`. У коричневого убрана упаковка ниже сфотографированной нижней кромки обложки. Меняется только прозрачность фона, RGB товара не синтезируется. Окружения повторно использованы из предыдущих тем.

Материалы собираются `python3 scripts/make-paper-hero.py` с Pillow, numpy и OpenCV. Исходная карусель сохранена в source-manifest.json; итог — public/hero/wallpapers.json и public/hero/paper-*.webp. Все пять слоёв товаров имеют прозрачное поле по краям. Размеры и вес в asset-check.json.

Проверено: `npx tsc --noEmit`, `npm run build`; все пять кадров на 1366×768, 375×812, 320×568, 430×932, 768×1024, 1920×1080, 812×375 с touch. Измеряется отсутствие пересечения листа, товара и панели цены, полное вписывание фото, размер целей от 44 px и отсутствие горизонтальной прокрутки. Проверен режим уменьшенного движения. JSON и скриншоты рядом. Серверные действия, src/lib, src/db, API и данные не менялись.

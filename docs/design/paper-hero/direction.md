# Заголовок на листе, товар крупным планом

Слева один бумажный лист с открытой перфорацией под диски, тонкой сеткой и печатным заголовком. Заголовок, описание и покупки образуют одну композицию на листе; отдельные прямоугольные плашки убраны. Шрифты и палитра бренда сохраняются: Cormorant Garamond, Golos Text, бумага #eee7db, лист #faf5ec, чернила #462c2b, акцент #823a31, линия #d0c3b5.

Справа крупная фотография настоящего ежедневника. Фон и товар — отдельные слои; фотография товара вписывается через object-fit: contain. Обложка, диски и края целиком видны на любом экране. Для сцены с подставкой отдельно учтена высота мрамора. Кадр с рукой исключён из карусели.

Телефон: компактный лист сверху, крупный товар в центре, цена и выбор кадра ниже. Настоящая картинка фона остаётся по всей площади. Нижнее меню не меняется. Без новых шрифтов, библиотек или генерации товара. Визуальный лист — элемент интерфейса по прямому запросу пользователя, не фотография продаваемого товара.

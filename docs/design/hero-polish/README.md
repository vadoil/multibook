# Полировка первого экрана

На десктопе новый кадр открывается слева направо CSS-маской за 0,72 с; предыдущая фотография остаётся под ним. На телефоне используется только прозрачность за 0,45 с, без маски и параллакса. При `prefers-reduced-motion` смена мгновенная, автолистание отключено.

Док: увеличение 1,14, название при наведении и фокусе, цели ≥44 px. На телефоне прокручиваются только миниатюры, кнопка паузы остаётся видимой; содержимое первого экрана не сдвигается. Параллакс только от мыши: ±6 px по горизонтали, ±4 px по вертикали, суммарно меньше 8 px. Поля слайда и серверные данные прежние.

Проверено в браузере: автолистание через 7 с, пауза и возобновление, удержание при наведении/фокусе, выбор Enter, промежуточная CSS-маска, ограничение параллакса, свайп и пауза в touch-контексте 375×812, уменьшение движения. Результаты — `checks.json`, скриншоты — `dock-1366.png`, `sheet-turn-1366.png`, `mobile-375.png`.

`npx tsc --noEmit` и `npm run build` проходят. Библиотеки не добавлялись; расчёты, действия, данные и API не менялись.

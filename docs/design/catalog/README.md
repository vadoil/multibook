# Дополнения к блокноту

По просьбе пользователя на карточках тетрадей и блокнотов с известным форматом вместо других готовых тетрадей показываются подходящие детали. Для А5 — до четырёх разных линовок, две обложки А5 и наборы из восьми дисков, отдельно 18 и 24 мм. Для мини-форматов отбираются их блоки и соответствующая комплектность дисков. Диаметр выбирается под толщину блока, о чём есть подпись.

Отбор использует существующие `attrs.format`, `ruling`, `pack`, `diameter`, наличие, цену и фотографии. Исключаются сам товар, неактивные позиции, товары без фото, с нулевой ценой и без остатка. При отсутствии нормализованного формата А5 определяется только по явному обозначению в названии; неизвестный формат не угадывается. У остальных типов остаются прежние рекомендации.

`src/lib`, `src/db`, импорт, server actions, API и расчёты не менялись. Добавлен только выбор существующих товаров для показа в карточке, явно запрошенный пользователем; данные каталога не правились.

Проверено:

- `npx tsx --test docs/design/catalog/complements.test.ts` — 3 теста: А5, мини-формат и неизвестная совместимость.
- Отбор дополнений проверен на 131 позиции из настоящего каталога из 257 товаров: формат и комплектность совпадают.
- `npx tsc --noEmit` и `npm run build` — успешно.
- В браузере на 1366 и 375 px: восемь дополнений для тетради А5, три блока для мини-куба; все изображения загружаются, горизонтальной прокрутки нет.

Скриншоты: `product-1366.png`, `product-375.png`, `complements-1366.png`, `complements-375.png`. Сценарий проверки в `browser-check.js`, запускается через Playwright CLI с локальным сервером на порту 3001.

При проверке также видны существующие 404 для `/how-it-works`, `/corporate` и `/favicon.ico` из прежней шапки магазина. Эти маршруты не относятся к отбору дополнений и в этом PR не изменены.

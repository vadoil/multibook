# Карусели конструктора и разные фотографии сторон

«Все» в выборе передней обложки теперь содержит все 26 моделей в горизонтальной карусели. Категории сохранены. Отдельная карусель показывает задние обложки; сначала идут модели с фотографией оборота. Работают свайп, трекпад, стрелки и клавиатура. Автоматической прокрутки нет; активная модель остаётся в видимой части списка, в том числе при открытии сохранённой сборки.

В «Что ещё добавить?» показаны все 24 активных товара раздела «Аксессуары» с фотографиями, актуальными ценами и ссылками на карточки. Ссылка на блоки А5 внизу убрана — количество блоков выбирается выше. Товары не обрезаются до нескольких рекомендаций.

Для пяти обложек с клапаном найдены и подготовлены отдельные снимки оборота. В режиме «Сзади» больше не подставляется фотография лицевой стороны. Если снимка нет, показана честная подпись. Комплекты представлены двумя фотографиями, а их переднюю и заднюю обложки можно отдельно показать в большом превью. Выбор передней обложки переключает превью на лицевую сторону.

Сохранение выбора при возврате из карточки аксессуара исправлено: Next мог восстановить старый снимок страницы с начальными деталями. Для текущей записи истории браузера сохраняются только ID деталей и количества, проверяемые по существующим вариантам. Цены, наличие и расчёт берутся из текущих данных, в истории не сохраняются.

## Данные и материалы

`src/lib`, `src/db`, server actions, API и имена полей форм не менялись. В UI-проекцию страницы конструктора добавлен список аксессуаров из существующего `listProducts({type: "Аксессуары"})`: ID, название, адрес, цена, фото, наличие. Ассортимент и цены в БД не исправлялись.

Новые снимки оборота и их проверенные углы включены в `docs/design/constructor-details/sources.json`. Пересборка — `scripts/make-constructor-artwork.py`; теперь 36 лицевых и 22 обратных стороны. 24 небольших фото аксессуаров собраны `scripts/make-constructor-accessories.py`; URL и SHA-256 — в `accessory-sources.json`. Новых зависимостей сайта нет.

Проверены импорт и публичный API Tilda: в текущей выгрузке 24 активных аксессуара. Разделы «Рубрикаторы» (280419021381) и «Рубрикаторы конструктор» (947205101062) возвращают 0 товаров. Это не утверждение об остатках производителя: чтобы показать нужные рубрикаторы и закладки, у владельца запрошены ссылки на их карточки. Несуществующие SKU и цены не добавлялись.

## Проверка

`npx tsc --noEmit` и production build проходят. На 1366, 375, 320 и 768 px проверены все 26 обложек и все 24 аксессуара, категории, стрелки, клавиатура, реальные разные изображения сторон, отсутствие повторной оплаты комплекта, несколько блоков, переход в карточку аксессуара и возврат с сохранением выбора. На 375 px дополнительно выполнен настоящий touch-свайп. Переполнения страницы и ошибок JavaScript нет, цели нажатия от 44 px. Сводка — `check.json`, скриншоты 1366/375 px находятся рядом.

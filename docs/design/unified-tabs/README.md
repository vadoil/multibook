# Единые табы магазина

Один стиль одобренных покупателем табов: светлая бумажная поверхность, контур, радиус 10 px, тонкие предметные иконки. Выбранный пункт выделяется акцентным контуром. Применено к категориям, фильтрам, навигации магазина, форматам и переключателям конструктора. Ссылки остались ссылками, переключатели — кнопками; роли вкладок не добавлялись.

На телефоне категории и фильтры прокручиваются внутри своих рядов; страница не выходит за ширину экрана. Планшет использует раскрывающееся меню, чтобы навигация помещалась.

Данные, фильтрация, выбор деталей, расчёты и защищённые серверные файлы не изменены.

Проверки: `npx tsc --noEmit`, production build с существующей QA-базой. 20 проверок страниц на ширинах 1366, 375, 320, 768 и 812 px: нет горизонтального переполнения, все видимые табы не меньше 44 × 44 px; меню закрывается Escape. Результаты — `layout-check.json`; скриншоты 1366/375 px находятся рядом.

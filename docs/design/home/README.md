# Главная: покупка готового или своя сборка

Первый экран двух спокойных концепций теперь прямо объясняет продукт: модульные блокноты со сменными листами, готовые коллекции и конструктор. Два крупных перехода доступны сразу. У показанного в кадре товара есть цена и ссылка на карточку.

Вместо длинного закреплённого блока с накладывающимися подписями — короткое видео сборки из настоящих фотографий. После замечания о креплениях совмещены отверстия листов и диски, в том числе при возврате листа. Фото с крупной упаковочной надписью «LINED MULTI» удалено из hero и блока механики. Тиснение реального товара сохранено.

Во второй концепции убран текстовый манифест. Сразу после hero — коллекция с фотографиями и реальными ценами. Все секции содержат фото, видео или пиктограммы. В третьей концепции также добавлены два явных пути покупки. Призывы в конструктор показывают фотографию и три группы деталей.

Демонстрационные адреса: `/design-preview/paper`, `/design-preview/journal`, `/design-preview/play`. Основная главная магазина остаётся до выбора концепции.

## Проверка

- `npx tsc --noEmit` — успешно.
- `npm run build` — успешно.
- Все три концепции проверены на 1366 и 375 px, без горизонтальной прокрутки.
- Кнопки перехода и управления видео не менее 44 px.
- Мобильное меню открывается и закрывается клавишей Escape.
- При сокращении движения показывается постер без загрузки MP4.
- Видео без звука, с кнопкой паузы; останавливается при наведении, фокусе и вне экрана.
- Отдельно проверены пауза, продолжение и загрузка восьмисекундного H.264 800 × 1000.
- `src/lib`, `src/db`, server actions, API, расчёт и выбор в конструкторе не менялись.

Скриншоты `*-1366.png` и `*-375.png`: полная страница; `*-hero-*`: первый экран. `journal-assembly-1366.png` — соединение листов и дисков, `assembly-frames.jpg` — этапы движения. Исходники видео и источники фотографий находятся в `motion/`.

# Видео сборки Multibook

Редактируемая композиция HyperFrames 0.9.84, 800 × 1000, 30 кадров/с, 8 секунд, без звука. На сайте используются готовые `public/media/notebook-build.mp4` и `notebook-build-poster.jpg`; HyperFrames и GSAP не входят в клиентский код магазина.

```sh
cd docs/design/home/motion
npm run dev
npm run check
npm run render -- -o ../../../../public/media/notebook-build.mp4
```

Фотографии настоящие, импортированы из Tilda. Геометрические маски выделяют лист, обложку и диски; изображений сгенерированных товаров нет. Координаты шести креплений взяты из фотографии обложки. Масштаб листа подогнан по центрам его отверстий; расхождение до маски составляет менее 2,3 пикселя на холсте 800 × 1000. Маска отверстий совмещена с центрами дисков. Лист возвращается в ту же позицию перед закрытием обложки.

- Обложка: https://static.tildacdn.com/ — точный адрес зафиксирован в `sources.json`.
- Лист в клетку: точный адрес зафиксирован в `sources.json`.
- Надписи интерфейса и управления вынесены из видео в HTML, все на русском.
- Логотип и тиснение на оригинальной фотографии товара сохранены.

`check` прошёл без ошибок. Два предупреждения `duplicate_media_discovery_risk` оставлены намеренно: одна фотография используется несколькими масками, а не дублирующимися клипами на таймлайне. Звук отсутствует намеренно: это тихая демонстрация внутри магазина.

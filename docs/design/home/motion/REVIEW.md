# Проверка движения

Сюжет: листы сходятся, диски входят в отверстия, обложка закрывается; лист снимается, возвращается и блокнот закрывается снова. Надписей и звука в видео нет — подпись и управление находятся в интерфейсе.

После замечания пользователя исправлена геометрия: центры креплений теперь общие для дисков и маски листа. Проверены кадры 2,1 с (соединение), 3,5 с (готовый блокнот), 6,19 с (возврат листа), а также переход к началу петли.

Проверка HyperFrames: ошибок нет. Два предупреждения о повторном источнике фотографий ожидаемы: из одного снимка получаются отдельные маски деталей. Фото оставлены без цветокоррекции, чтобы цвет реального товара сохранялся.

Это анимационная композиция из фотографий каталога; она показывает механику соединения. Тиснение оригинальной обложки сохранено. Безопасное поведение на сайте: автовоспроизведение останавливается при наведении и фокусе, ручное продолжение работает сразу с касанием и клавиатурой. Отдельная кнопка паузы, остановка вне экрана и статичный постер при сокращении движения сохраняются.

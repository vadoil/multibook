# Магазин после первого экрана

Вместо повторяющегося объясняющего hero главная сразу показывает готовые блокноты и тетради: восемь реальных товаров, названия, цены, отдельные ссылки в категории. Сохранён приоритет готовых товаров, отмеченных для главной в админке. Для знакомых премиальных моделей выбраны чистые фотографии из их галерей без рекламных плашек. Рисунки и синтетические товары не используются. Дисковый переплёт объясняется один раз; приглашение в конструктор остаётся отдельным разделом.

Каталог: категории, формат, линовка, материал, наличие и прежняя сортировка. Используются только существующие `attrs`, `stock` и `price`. Дополнительных полей, миграций и изменений в src/lib нет. Параметры `format`, `ruling`, `material`, `available` живут в URL. Сортировка и страницы сохраняют выбор; изменение фильтров возвращает на первую страницу. Категория начинает новую выборку. Параметры дисков `d` и `m` сохраняются.

На телефоне категории и значения фильтров можно листать горизонтально, крупные элементы доступны пальцем; формат и линовка видны сразу, материал раскрывается. Длинное общее описание скрывается, чтобы быстрее показать товары. Нижняя навигация и покупка сохранены.

Проверки: TypeScript, production-сборка, реальные сценарии фильтрации с сопоставлением карточек исходному каталогу на отдельной копии базы, переход на вторую страницу А5, сортировка, очистка пустой выборки. Подробности в flow-check.json и layout-check.json. Скриншоты 1366 и 375 px рядом.

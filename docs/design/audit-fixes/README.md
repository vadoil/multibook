# Правки по аудиту

- Подписи товаров и категорий от 12 px на телефоне; материал на карточке берётся из `attrs.material`, при отсутствии не выводится.
- Карточки используют вторую настоящую фотографию с возвратом к первой, если второй нет. Условий по названию товара больше нет.
- «Весь магазин» ведёт в общий каталог, «Выбрать готовый» — в блокноты. Внутренние стрелки направлены вправо; диагональная стрелка оставлена у Ozon.
- Категории выводятся серверным визуальным компонентом `DesignCategories` из существующего `TYPE_LABELS`. В `DesignConcept` передаётся готовая разметка через слот; новых полей товара и серверных вычислений нет.
- Галерея товара переключается кнопками-миниатюрами с `aria-pressed`, под фото виден номер. На телефоне цена и существующий `AddToCart` закреплены внизу; логика корзины не менялась. Условия доставки и оплаты оформлены с пиктограммами.
- Пять сервисных страниц получили общие оформление и навигацию. Исходные тексты и реквизиты в файлах страниц не менялись. Собственная 404 предлагает магазин, конструктор и категории, показывает настоящую фотографию.
- Стили концепций импортируются только главной и `/design-preview`. Общие шапка, подвал, поля и кнопки остаются в `store.css`. Начальная загрузка CSS корзины/кабинета/конструктора — 52 726 байт; стили концепций и обоев отсутствуют, см. `css-check.json`.

Проверки: `npx tsc --noEmit`, `npm run build`; три существующих теста совместимости дополнений. Production-сборка проверена в браузере на 1366 и 375 px: галерея, нижняя покупка → корзина и счётчик, главная, категории, сервисные страницы, 404 (HTTP 404), кабинет, корзина, конструктор, вход тестового администратора. Горизонтального переполнения и ошибок JavaScript нет; контрольная сборка конструктора остаётся 1 767 ₽.

Скриншоты WebP сохранены рядом: `product-*`, `home-*`, `featured-*`, `categories-*`, `delivery-*`, `returns-*`, `contacts-*`, `privacy-*`, `corporate-*`, `404-*`, `catalog-*`. Результаты — `checks.json` и `screenshots.json`. Проверки действий выполнены на отдельной локальной копии базы с фиктивным пользователем; эта база не публикуется.

Ветка основана на `design/hero-polish` (PR #8). `src/lib/*`, `src/db/**`, `actions.ts`, API, имена и действия форм не менялись.
